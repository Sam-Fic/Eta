# v3.11.13 — 记忆写入失败自救引导（引导优先增益）

## 背景

记忆系统现状已完善：memory_write 提供 4 种编辑模式（replace_section / replace_range / append / clear）、
护栏恰当（防重复标题、防丢失核心段、1MiB 上限、DELETE_ALL 确认）。审查定位一处"编辑自由度"的真实缺口：
**模型写错（行号算错、标题歧义等）后只有错误消息，没有"当场怎么改"的自救引导**，
导致"写完报错 → 原样重试 → 再报错"的来回。

遵循引导优先理念：不放开护栏、不加新功能，只让模型写错后能**当场自我修复**。

## 修复

### 逻辑修复 / prompt 约束（引导层）

1. **MEMORY_RANGE_INVALID 引导增强**（`AgentMemoryStore.replaceRange`）：
   报错附可操作路径——「start/end 需 1 ≤ start ≤ end ≤ 行数；先 memory_get 预览实际行号再试；
   只改整块内容改用 mode=\"replace_section\" + section，不必手算行号」。
2. **系统提示补自救说明**（`AgentPromptBuilder` 记忆段落，prompt 约束类）：
   「memory_write 报错时按提示自救：先 memory_get 预览实际标题/行号再重试，不要原样重发同一套参数；
   删除整节用空 content，清空全部用 mode=\"clear\"+DELETE_ALL」。

### 未改动（维持）
- 4 种编辑模式、护栏（防重复标题/防丢核心段/1MiB/DELETE_ALL 确认）、memory_get 三通道读取、revision 乐观锁——全部不变。

## 验证

- 编译 + 全量回归：新增非环境失败 = 0。
- 本改动为纯 message/prompt 增强，无行为契约变化。

> 减少原样重试的来回；记忆可被更顺畅地编辑更新。
