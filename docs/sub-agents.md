# 主代理与子代理

设置 → 模型功能 → 子代理，可动态添加、重命名、启用／停用或删除代理。
每个代理独立设置职责（执行、审查／总结、图片生成、视频生成）、任务复杂度（简单／常规／复杂）、模型与思考深度。
职责/模型/默认分辨率更改下次运行生效；模型并行限额即时调整调度。设置页另有统一诊断日志开关。
配置以稳定 UUID 保存，名称或排列不参与统计归属；首次迁移保留旧四代理的模型、思考覆盖与顺序。
同一模型可用于多个独立代理，也可与主代理相同；未指定复杂度时不推断模型强弱。
当前聊天模型负责调度和最终验收。长按输入栏「助手与模型」按钮进入设置页的子代理配置页（预设组列表 → 组内代理编辑），不单独做会话内页面；默认开启，下一次运行生效。

## 委派、排队与角色

`delegate_task` 的 role 为 research（默认只读分析）、implementation、review、summary、image_generation 或 video_generation。
可用稳定的 `agent_id` 或本轮目录中的 `worker` 选择代理；两者同时提供必须指向同一个代理。
主代理可见每个可用代理的名称、职责、用户指定复杂度和有效思考深度，据此选择；复杂度不是性能评测。
未指定代理时按职责和当前排队负载选择；未配置的职责返回 ROLE_NOT_CONFIGURED，不静默换角色。
仅启用且模型配置有效的代理加入本次运行；职责/模型配置变更不修改本次运行快照；并行限额是共享调度策略，可即时调整。

没有固定的代理数量、全局并发数或每轮 16 项任务上限。同一代理也可并行多项任务，按“提供商ID+API模型名”的共享限额调度，超额任务排队。
不同代理可以并行；取消任务后，其配额占用要等执行体和清理真正退出才释放，不因取消future就虚增可用空位。
`get_task_result` 返回 queued／running／awaiting_decision／终态、稳定代理 ID、结果、project、workspace_id 与 workspace_path。
排队不消耗执行／压缩预算；实际开始后文本每个执行片段180秒，预算用完等待主代理继续或取消；压缩另有累计180秒硬预算。进入最终封存后不再暂停。图片180秒、视频600秒硬超时，不自动重发。
取消排队任务不创建工作树；父运行结束会取消运行中和排队中的任务，未合入代码不自动删除。
调用方取消、线程中断或 `AgentRunCancelledException` 记为 cancelled，不会写成 `SUB_AGENT_FAILED`。其它失败只附加异常类型，不附上游正文。
原始委派上下文和结果按敏感工具内容处理，不进入持久会话。

## 主代理必须并行委派

启用子代理后，运行时把调度规则单独放在长操作规范之前，而不是埋在其中。
两处或以上可以分开阅读的源码、协议或界面，必须在同一轮并行 `delegate_task`，不能先自己读完再决定委不委派。
research / review 可以 `read_file` 和 `list_directory`，但不能执行 shell、GUI 或浏览器。设备日志、数据库和实机请求留在主代理，不能因此把源码阅读也留下。
多文件调查不是琐碎任务。一句问答、一次状态查询、重复的付费生图，以及同一文件的连续修改不要拆开。
没有兼容的 research、review 或 implementation 代理时才自己完成对应阅读，并说明原因。派发后必须取回结果再下结论。


## 委派参数预检与有界补全

`task` 必须是顶层非空说明，不能用 `context` 替代。参数验证失败时不会调用协调器或创建子任务。
客户端最多请求两轮参数补全，同一批多个缺参调用只计一轮；修复结果按 tool-call ID 配对，客户端不重放成功调用。
界面显示参数补全提示，而非把未执行的预检当作已派发任务失败。
连续无效则明确显示 DELEGATION_ARGUMENT_REPAIR_EXHAUSTED，移除本轮新委派工具；已有子任务仍可查询或取消。
该机制不编造任务内容，也不保证有问题的模型必定能补齐参数；最后失败仍真实呈现。

## 图片与视频生成代理

图片／视频职责只允许选择相应的生成模型；切换到不兼容职责时清空模型引用和思考覆盖，不把生图模型当作聊天代理调用。
主代理以 `role=image_generation` 或 `role=video_generation` 委派，`task` 为生成描述，`context` 可补充要求；不传 project 或 workspace_id。
使用已有图片生成接口或视频生成及轮询接口，不开放 Shell、文件编辑、研究工具或递归委派。
产物写入当前会话的媒体缓存，完成结果包含实际文件的图片／视频 Markdown；主代理取得成功结果后才能展示，不把文字说明当成媒体产物。
生成请求、视频轮询和下载绑定子任务取消；共用所选提供商/模型的并行上限，排队不消耗预算，图片执行预算 180 秒、视频 600 秒（覆盖视频接口轮询窗口）。取消本地请求不等于撤销提供商已接收的计费任务。
生成任务没有对话 token 上下文统计，菜单仍显示该任务和状态，用量详情明确说明不适用，不伪造零用量或百分比。
当前委派入口为文本描述生成，不自动把其它会话附件上传给媒体接口。

## 一项目一目录

项目任务必须明确指定 /workspace/<项目名>，不默认 Eta，不允许使用 /workspace 或 mounts。
项目需已初始化 Git 且至少有一个提交，创建实现工作树前必须没有未提交源码改动。
换项目传新 project，旧项目的工作区 ID 不能在新项目使用。

.agent/worktrees/<ID> 存独立 detached worktree；.agent/results/<ID>.json 仅记录基线、
状态和交付提交，不记录密钥或任务正文。不创建或推送临时分支。.agent 应加入 Git 忽略规则。
使用设置中所选 Linux，需要 Python 和 Git；不可用时返回错误，不改走 Android Shell。
只有依赖探测缺少 Python/Git 时返回 WORKSPACE_LINUX_PYTHON_GIT_REQUIRED；脚本启动或传输失败返回 WORKSPACE_EXECUTION_FAILED，环境权限错误保留原错误码。

1. implementation 传 project，创建独立工作树。子代理仅通过 workspace_file 读写源文件。
2. 完成后运行时提交并冻结，主代理获得工作树路径及 ID，在该路径执行构建／测试。
3. review 传同一 project 和 workspace_id，只读检查固定提交。
4. 主代理读取审查结论、核对 diff 和测试后，明确调用 manage_agent_workspace 的 merge。
   reviewed 仅代表审查流程完成，不代表审查无问题。快进合入要求主仓库干净且仍在基线，交付未变。
5. 合入后删除工作树；失败或取消保留现场，list/inspect 可查询，明确放弃才 discard。

## 权限与恢复

workspace_file 提供 list_files/read/diff/write/delete，运行时绑定项目和 ID，模型不能覆盖归属。
相对路径拒绝 ..、Git 元数据、.agent、符号链接、硬链接和特殊文件。文件上限 64 KiB、输出分页。
审查角色只能读取。子代理不能运行任意 Shell、操作手机、发送消息或创建子代理。
研究／总结角色的 read_file、list_directory 支持所选 Linux 的 /workspace、/var/minis、minis:// 路径，先映射宿主位置，再按原有文件权限读取；实现／审查仍仅使用绑定工作树的 workspace_file。
主代理仍有原有权限；目录隔离不是主代理 Root Shell 的系统沙箱。

跨进程项目锁串行化文件操作、冻结、合入和回收。审查期间不可合入或删除。
遗留任务租期到期后 inspect 标记待处理并保留现场。不再以 8 个工作树限制动态代理数量；每任务累计写入预算 16 MiB，创建前检查至少 512 MiB 剩余空间；不自动删除未合入改动。
重启不恢复模型循环，但可在原项目继续查看和处理交付物。
当前不支持自动初始化无 Git 项目、自动 rebase 或子代理任意命令执行。

## 验证

Python 集成测试覆盖真实 Git 隔离写入、冻结、审查、快进合入、回收，跨项目归属、
越界/符号/硬链接、脏主仓库、基线变化、失败保留、过期恢复和分页。
Kotlin 测试覆盖职责路由、角色缺失、工作区参数绑定、只读执行限制与取消。
子代理使用原创 SubAgents 矢量图标：一个主机器人分支连接两个子机器人，设置入口和委派／结果／取消／工作区工具统一使用，不再复用记忆图标。设计稿见 `assets/sub-agents-icon.svg`。

## 手动与自动压缩

手动压缩跟随上下文圆环选中的对象：主代理压缩父会话 history，运行中的文本子任务按本轮 runId 和 taskId 精确请求自己的 controller；请求发出后切换选择不会改变原目标。请求不广播、不影响其它代理。已结束、排队中或媒体任务不支持压缩，不自动回退主代理。
子任务在等待压缩或压缩时结束，会清除 pending/compacting 状态并保留终态和结果；迟到事件不能复活任务。主代理压缩期间，其它子任务完成的结果保存在协调器，恢复后仍可查询。不带 task_id 调用 get_task_result 可分页找回本轮任务 ID／状态，再按 ID 读取结果；列表不回传敏感结果正文。

### 子代理自动压缩

子代理使用独立上下文，默认开启自动压缩；用户在上下文压缩设置中明确选择的开/关优先。
以该子代理模型配置的上下文窗口计算压力，沿用共享的压缩模型选择、接口模式和推理策略；
未选择自定义压缩模型时，由子代理自己的模型压缩。没有配置有效上下文窗口时，不猜测容量开启压缩。
约 80% 窗口压力触发压缩，保留最近完整工具批次；子代理压缩仍归属父会话用量。
子代理摘要仅在独立执行上下文中使用，不创建永久压缩归档，也不增加子代理工具权限。
若仍超限且无法继续压缩，返回 SUB_AGENT_CONTEXT_LIMIT 给主代理并保留实现工作树，避免无交互暂停直到超时。

子代理编辑集中在设置页的一套页面：预设组列表（添加／重命名／删除组）与预设详情页（组内代理的职责、任务分工、模型、思考深度、并行上限）。输入栏长按入口与设置页入口共用这两条独立路由，不再单独承载会话协作页；变化从下一次运行生效。


## 上下文统计与并发压缩

长按上下文圆环打开统计对象选择器；单击仍显示用量详情。选择只切换查看对象，不切换请求模型。
主代理与已启动子任务复用 AgentLoop 的用量事件：优先接口输入 token，工具批次后按账单基线加增量投影，首次请求和压缩后无账单时采用共享本地估算。未知窗口保持未知。
选择器显示主代理与实际已委派的各项任务，不显示尚未接任务的配置模型。同一个模型的不同任务分开列出，使用运行时模型名称、代理名称、短任务 ID 与状态区分；按 taskId 精确选择，独立任务的占用绝不合并或累加。统计使用任务创建时的模型快照，不随设置中的改名、换模型或删除而错配。get_task_result 的 context_usage 返回模型、窗口、当前占用、是否估算、累计输入输出、压缩中标志、压缩次数及压缩前后占用。
UI 通过运行时事件直接接收统计，主代理压缩或等待时仍可更新。压缩状态按模型/任务在消息底部逐行展示，任意一路完成或取消即清除对应提示。
每个 AgentLoop 只暂停自身后续请求；主代理压缩不会停止已启动子代理，子代理结果由协调器保存至父运行结束。执行预算和累计压缩预算用单调时钟分别计时，压缩超时返回 SUB_AGENT_COMPACTION_TIMEOUT。
工作树租期为 420 秒，覆盖两段预算及清理余量；父任务停止仍立即取消子任务。并发随本轮启用代理数量变化，同项目可创建多个隔离实现工作树，但合并仍要求基线未改变，不自动 rebase。


## 子代理独立思考深度

单击预设详情页中的模型行选择该代理模型，长按模型行打开与主代理相同样式的“调整思考深度”滑块弹窗，只展示该模型支持的档位。模型行显示当前生效的思考深度；未配置模型的代理可单击选模型，长按不触发模型选择，没有可切换档位的模型显示说明。
深度覆盖保存在每个子代理代理独立的偏好中，不写提供商模型默认深度，也不修改其他会话的主代理配置。同模型占用多个代理时可设置不同深度。未设置覆盖时沿用模型默认值；更换或清除代理模型会清除该代理覆盖。
设置跨会话用于该子代理代理，在下一次主代理运行加载子代理配置时生效，已运行的任务保持原来的深度。

子代理选模型弹窗（预设详情页入口）均提供“无”，选择后清除该代理模型和独立思考覆盖，下一次运行不再加载该代理，不影响其它代理。


## Material 控件与职责分工

子代理设置使用 Material 3 分段列表、标准图标操作与描边字段。详情页的执行代理分工按钮使用轻量描边，不再使用厚重灰底；非执行代理显示名称／职责而非分工按钮。
分工与职责菜单使用选中背景色及无障碍 selected 语义，不显示勾选图标。子代理模型选择器同样使用选中背景；模型分组、模型选项、“无”和关闭操作不产生点击涟漪。
只有执行代理具有简单／常规／复杂任务分工。审查／总结、图片和视频生成代理不展示分工，旧配置读入和后续写入会清除无效分工；从执行切到其它职责时也清除，不会切回后意外恢复。委派说明不再为这些职责声明任务分工。

### 代理行紧凑布局

代理行按确认的效果稿为单列紧凑行：名称、模型和提供商/思考信息统一在左侧，执行代理右侧为小尺寸任务分工入口（触摸区域由官方 IconButton 保证至少 48dp）。非执行代理右侧为模型选择箭头，不展示任务分工或重复职责说明。该行由预设详情页与行内配置弹窗共用，选中背景高亮及无涟漪规则保持不变。

### 设置页手机比例分组布局

按确认的竖屏效果稿，设置页取消代理外框和嵌套字段边框，使用细分隔线分组；模型、职责、任务分工、思考深度改为左侧图标和标签、右侧取值与箭头的完整设置行。提供商作为模型下方的小标识，长模型名可换行。只有执行代理显示任务分工，图片／视频代理不显示思考深度。
添加子代理固定在底部并避让导航栏，列表独立滚动；启停、重命名、删除和模型长按手势保留。选项背景高亮、不显示勾选和无涟漪规则不变。主题色跟随应用，不硬编码效果稿中的浅紫色。

### 生图参数透传与结果验收

- `delegate_task(role="image_generation", image_options={...})` 支持 `aspect_ratio`、`resolution`、`size`、`n`、`quality`、`response_format`。明确的尺寸要求必须放在结构化字段里，不能只写进 task/context。
- 参数由 coordinator → runtime → media runner → image client 按任务传递；覆盖本次请求中冲突的模型默认值，不改供应商配置。未知字段、无效值及非生图任务使用 image_options 在创建任务前拒绝。
- 分辨率统一使用 `low/medium/high/ultra`（低/中/高/超高），旧 K 值仅兼容解析。生图设置有“默认分辨率”按钮，语义档位不等于固定像素，unsupported 档位拒绝而非自动降档。
- 当前实测 Grok 中转独立采用 size 路径，只验证低、高档及指定比例；不能泛化至其他 Grok 中转。细则见 `image-parameters.md`。
- 真实文件保留原尺寸，校验比例、精确尺寸和已验证档位。缺少档位像素映射时明确 UNVERIFIED；不裁剪、缩放，不因HTTP失败或空结果自动重发或回退Chat。
- 编辑路径按显式协议选择；Grok实测预设未验证编辑，会拒绝而不丢参考图。
- 测试分为纯 JVM 参数/任务传递测试和 Robolectric + 拦截器请求体/真实尺寸测试，均不访问付费生图接口。


### 设置页对比与菜单

- 设置行图标和文字使用 `onSurface`，提供商标签在模型名左侧。底部「添加子代理」为居中文本按钮，无加号。
- 职责、任务分工、更多操作和预设详情页的分工菜单共用 `SubAgentDropdownMenu`：按最长选项自适应宽度并保留少量左右内边距，描边无投影，选中行为 `surfaceVariant` 淡灰背景而非勾选。打开/选择/开关/添加补齐 `TouchHaptics.click`。

## 模型并行上限与超时决策

- 每个子代理的“思考深度”下方有带图标的“并行上限”按钮，只设置其已绑定的提供商/API模型，不列出未使用模型。正整数无产品档位上限，0表示不限；默认1。同一提供商同一API模型跨代理身份和父run共用配额，不同提供商独立。
- 同一子代理可同时承担多个任务；无全局固定最大数量。任务仍受手机资源和上游限流约束，不建议盲目设为不限。排队不消耗执行/压缩预算；保存新上限即调整调度，降低不取消已开始的任务，后续任务等空位。
- 协作默认优先把独立、有价值的任务并行派给匹配代理；同文件冲突、先后依赖及成品审查仍顺序执行。
- 文本执行片段用完进入 `awaiting_decision`，主代理用 `continue_task(task_id)` 增加下一片段或 `cancel_task` 停止。同一任务、模型上下文、工作树与已执行工具保留，续作不是重新委派；在途请求不因预算边界重复发送，在安全检查点挂起。
- 等待主代理时停止执行计时，但在途压缩生命周期继续记录、仍受独立累计压缩预算限制。媒体和压缩硬超时不续跑，不自动重复付费请求。
- 工作树等待时续租，主代理run结束仍取消子任务并保留未合并改动。已结束的 timed_out 条目在30秒后仅从上下文统计菜单隐藏，不删除任务结果/代码；等待决定的任务单独保留。

### 子代理诊断日志

- 子代理设置提供诊断日志开关（与应用统一文件日志开关同步），在设置的诊断区导出 ZIP。搜索 `SubAgentDiag` 或任务 UUID 可定位一次调用。
- 记录 schema、父run引用、任务ID、代理/提供商/模型匿名引用、职责/状态、当前阶段、排队/执行/压缩/等待决策耗时、并行限额及活动/排队数量、HTTP码、工具成功状态、异常类型和本地代码位置。
- 覆盖创建、拒绝、开始、请求/响应/重试、工具起止、压缩、工作树准备/封存/租约故障、完成/取消/超时/续作与worker释放；阻塞阶段30秒输出一次心跳。高频文本块不逐个记录。
- 不写用户提示词、任务context、模型正文、工具参数/结果、URL、认证头、文件路径或原始异常消息。只从HTTP错误消息提取数字状态码；未知错误码替换为UNCLASSIFIED。日志失败不能改变任务结果，文件使用现有轮转与显式导出机制。

### 并行上限入口

每个子代理在“思考深度”正下方提供带并行图标的“并行上限”按钮，直接编辑此代理绑定的提供商/API模型；不再在页面顶部展示全部模型选择列表。未选模型或模型不可用时禁用；尚未适配媒体思考不影响并行上限设置。相同提供商/API模型的多个代理仍共享调度配额与存储值，各入口同步显示；换绑/删除后旧弹窗不能写入。0 表示不限。
