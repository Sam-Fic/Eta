# Eta副屏网页预览与持久配对

此目录配套 Eta 的认证预览服务和 `tools/vd-preview-gateway` 中的 3070 页面。
网关代码基于 agent-mobile-use，保留原 MIT 许可和版权；未改写旧 owner 的创建、关闭或输入协议。

## 使用方式

1. 使用包含本次修复的 Eta APK 和配套网关；仅更新网页或 APK 其中一端不构成完整升级。
2. 首次在 Eta 设置的副屏卡片点击“网页实时预览”，授权本机浏览器。没有副屏时也可打开，网页只显示空列表，不会创建副屏。
3. 在网页勾选“记住此浏览器配对”。以后用同一个浏览器直接打开 `http://127.0.0.1:3070/`，或刷新网页，即可恢复Eta模式。不勾选则只保留本页内存中的临时连接。
4. 页面选择实际返回的副屏；身份同时绑定 displayId 和 uniqueId。点击“手动刷新”获取列表和画面，不轮询、不自动操作副屏。
5. “手动关闭空副屏”沿用独立控制权限、准备确认、单次 nonce 提交和后端状态复验。正在执行、身份不明或已有不确定操作时会拒绝；不强杀、不重放、不调用模块的旧关闭接口。
6. 网页的“忘记此浏览器配对”清除此浏览器记录并断开当前页面，不关闭副屏。App 的“撤销网页授权”停止监听并撤销所有浏览器原凭证；重新授权会生成新的凭证。

直接访问网页且没有授权或已记住的配对时，仍需首次从 App 授权，不会扫描端口或读取 owner 私有 token。
`localhost:3070` 与 `127.0.0.1:3070` 是不同浏览器源，配对不能混用。仅支持当前手机本机浏览器，不增加公网或局域网访问权限。

### 生命周期和离线状态

- 退出设置页不停止预览服务；同权限重新打开入口复用原端口和凭证。
- 主进程下次启动时，在后台仅恢复已明确开启的配对。未配对时不监听，更不会创建副屏。凭证在 App 私有 no-backup 目录中原子保存。
- 服务依赖 Eta 主进程，不是独立常驻的前台服务。进程被杀或手机重启后，在 Eta 主进程再次启动前网页会显示离线；启动后可手动刷新，不必重新配对。
- 已保存端口被其他程序占用时失败关闭，不换随机端口、不自动抢占。可在 App 撤销后重新授权。
- HTTP 401 会使当前页面丢弃过期授权，并清除匹配的浏览器记录；网络中断则保留配对供手动重试。存储被禁用时明确提示，仍可使用本次授权。
- 当前接口只列出 Eta 能认证的 owner，不是所有 Android 显示器的全局管理器。副屏结束或身份变化不会回退到主屏或旧模块。

## 安全与边界

- 预览服务仅绑定回环地址，校验 Host、Origin 和独立 Bearer 凭证；不公开 owner IPC 凭证。
- 浏览器读取连接 fragment 后立即清除；不把凭证写入 query、sessionStorage、日志或图片 URL，也不传给 Go 网关。
- 仅在用户勾选后，网页专用 read/control 凭证会保存到该本机页面的 localStorage；它们不是 owner IPC 秘密。请只在可信浏览器及可信网页模块上记住配对。新链接不会继承旧记录的控制权限；旧标签页的 401 不会删除另一标签页刚保存的新配对。
- 只读与控制模式切换会轮换整套能力；权限校验、精确身份检查和单次关闭确认不因持久化而放宽。
- 帧协议为 PNG，校验 MIME、签名、大小及返回的副屏身份。
- 切换来源/副屏时中止旧请求并丢弃迟到响应；展示用 Blob URL 会释放。
- 保留原有敏感应用截屏排除策略。

## 构建与验证

在已配置 Go >= 1.22 的 Linux 环境执行：

```sh
./scripts/build-vd-preview-gateway.sh
```

脚本先运行 Go 测试（包括 Node.js 前端测试），再交叉构建 Linux/ARM64 网关。
输出在 `build/vd-preview-gateway-arm64/`，包含二进制、许可、说明及 SHA-256 清单。
脚本不安装、不重启设备服务、不操作任何现有副屏。

完整 Android 构建仍需仓库要求的 JDK 与 Android SDK；宿主 JVM/模拟画面联调通过不等同于真机验收。

## 安装边界

不要在仍有未交付副屏任务时重启 owner、杀进程或替换正在运行的服务。
本目录不提供自动安装或清理脚本。部署应分别确认 APK 与网关版本，保留旧二进制以便回退；
网关不是 owner；升级后首次仍需由 Eta 提供有效的网页授权，之后才可按需记住配对。
